# 驾驶舱（Cockpit-Web）

一个 `index.html`，用 Edge / Chrome 打开，浏览器直接读取整个库，把「机械事实」画成看板。没选过文件夹时，先显示内置的虚构示例库（林舟），方便给别人演示；选了自己的库，示例和介绍自动隐藏。

- **不装任何东西**：不要 Python / Node，也不依赖 Obsidian 插件。
- **只读**：Markdown 只在本机浏览器里解析，不上传、不改文件。
- **永远是现在**：每次打开、每次切回这个标签页都会重新读库。

## 怎么用

1. 用 Edge 或 Chrome 打开 `cockpit-web/index.html`（双击或拖进浏览器）。
2. 打开就是示例库。要看自己的库，点右上角「打开我的库」，选放着 `CLAUDE.md` 的那一层。
3. 之后打开会记住文件夹；浏览器重启后可能要再点一次「继续读取」，这是浏览器的安全规定。
4. 点任何文件名，会在 Obsidian 里打开那篇笔记（示例库里的文件名不链接）。

## 页面上有什么

从上到下：

| 区块 | 内容 |
|---|---|
| 🧭 应对手册 | 证据链图：原始记录 → 情境 → 策略。点一条策略，连线标出它被哪些记录证明过（绿 = 照着做有效，红 = 照着做无效，虚线 = 只是问题出现），下面列出日期和原话；点一条记录，看它算进了哪条策略。记录多于 24 条时只画被策略引用的，并注明还有几条没被引用 |
| 🪪 侧写与 AI 维护记录 | `C-WhoRU.md` 的近况、画像各是哪天更新的、有几行，加上画像前几条；项目日志里 AI 最近做的 6 件事 |
| ⏰ 截止日与积压 | 截止日雷达（逾期、今明两天、14 天内、更远）；沉淀债（回忆录缺口、情境综述落后、待明确、Inbox 积压） |
| 🟢 项目 | goal、更新时间、停滞标记、待办完成度、最新一条进展日志、前 3 条可动手的待办 |
| ✈️ 旅行计划 | 状态、距出发几天、待办完成度 |
| ❤️ 生活与捕捉 | 捕捉日历、情绪分布、情境分布、捕捉 vs 蒸馏（按月）、最近的情绪记录 |
| 🩺 库体检与等级核对（折叠） | 给 AI 看的机械检查：策略等级和次数、次数和链接数对不对得上；规则文件、断链、字段取值、目录与 type 等 11 项 |

## 为什么这么设计

- **只放事实，不放判断**：对应规则铁律 6「判断不落盘」。「今天该干哪件」会过期，过期了有害，所以不落在页面上，直接问 AI。经验的证据等级是 AI 写在文件开头的，页面只照抄，并核对次数和等级对不对得上。
- **规则跟着 CLAUDE.md 走**：目录表、根目录文件、每种 type 放哪和要哪些字段、goal / field / status / 情绪词表，都在每次读库时从 `CLAUDE.md` 读出来。改规则后刷新页面就能跟上，不用改代码。读不到规则时用代码里的默认值，并在体检第 0 项提示。
- **单个 HTML + 浏览器读文件夹**（File System Access API）：做成要启动服务器的程序，门槛高到最后没人用。
- **配色**：图表只用 1–2 个分类色，状态永远是「色点 + 文字」，不只靠颜色；每个图下面都有「表格视图」。

## 已知限制

- Firefox / Safari 没有文件夹读取接口，会退回成每次都选一遍文件夹。
- 只认 `- [ ] … 📅 YYYY-MM-DD` 写法的截止日期。
- 只读：勾掉待办要回 Obsidian 做。
- 断链检查不区分「有意的占位链接」和真断链，要看明细判断。
